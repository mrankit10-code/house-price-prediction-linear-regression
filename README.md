# 🏠 House Price Prediction using Linear Regression

A machine learning project that predicts house prices using the Ames Housing Dataset and Linear Regression.

## 📌 Project Overview

The goal of this project is to build a regression model that can predict the sale price of residential properties based on different features such as:

- Overall Quality
- Living Area
- Garage Area
- Total Basement Area
- Year Built
- Number of Bathrooms
- Number of Rooms
- Neighborhood
- And many other property features

The project focuses on understanding the complete machine learning workflow from data preprocessing to model evaluation and prediction.

---

## 🎯 Objective

Build and evaluate a Linear Regression model for predicting house prices and analyze how different preprocessing techniques affect model performance.

---

## 📊 Dataset

**Dataset:** Ames Housing Dataset

The original training dataset contains:

- **1,460 rows**
- **81 columns**
- **SalePrice** as the target variable

### Target Variable

`SalePrice` — The selling price of the house in dollars.
